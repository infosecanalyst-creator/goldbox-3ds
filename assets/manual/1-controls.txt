# Controls
## Quick start
Everything can be done with the stylus or the buttons; the keyboard only opens by itself when the game wants you to type (names, riddle answers).

Outside combat the game is on the top screen and the touch screen shows big buttons for whatever the game is asking. In combat the game moves to the touch screen so you can tap to aim. ZL (or the SWAP button) flips the screens any time.

Every touch button also works with the buttons: a gold ring shows the button A will press.

## Buttons
A: Enter (pick the highlighted choice).

START: the menu: Resume, Manual, Save Game, Journal, Left Hand and Exit Game. It opens any time, also while you type. Exit Game asks first, and saves for you when the party is in the world (see Saving and leaving).

B: Esc (back out). On a Yes / No question B answers No. (Only "Save this character?" waits for a real Yes or No.)

X: Yes.

Y: Space. While typing, Y deletes a letter.

D-Pad / Circle Pad: walk and turn in the 3D view, step through menu words, move the highlight in lists, or move the gold highlight in menus such as the start menu.

L / R: previous / next party member. In a list, the D-Pad moves the highlight. In combat, L and R move up-left and up-right; the C-Stick left and right move down-left and down-right. In the Aim menu, L / R pick the previous / next target.

C-Stick up / down: page up / down in long lists.

ZR: use the touch-screen buttons with the D-Pad. The gold ring moves to the buttons (ESC, YES, NO, ENTER, KEYS, SWAP, BOOK and the game's choices; greyed ones are skipped); the D-Pad moves it, A presses the ringed button. B or ZR goes back without pressing anything. After a press the D-Pad walks again.

ZL: swap screens, any time.

Left hand: START, then LEFT HAND, or open the manual (BOOK) and tap LEFT: OFF / ON at the bottom of its touch screen. The D-Pad and the Y, A, B, X buttons swap jobs: Y is up, A is right, B is down, X is left, and the reverse, so the stylus can be held in the left hand and every control in this manual follows the swap. It is remembered.


## The gold ring
In menus and lists the D-Pad moves the game's highlight, and the gold ring sits on the matching big button; A presses it (it lights up and clicks, as a tap would).

On the keyboard and the number pad the D-Pad moves the ring between the keys and A presses the ringed key. ENTER (OK on the number pad) is one of the keys.

While you explore, the D-Pad walks, so the ring stays on the menu word the game has highlighted (A picks it). Press ZR to move the ring to any other button.

## Touch screen
With the big buttons (game on the top screen), one tap picks.

With the game itself on the touch screen the lines are small, so a tap is forgiving: the first tap on a menu line or a list entry only moves the highlight there, and a second tap on the highlighted line picks it. A word on the game's bottom menu line is picked with one tap.

Tap a name in the party list to select that character.

In the 3D view (game on the touch screen): tap the middle of the view to walk forward, the left or right side to turn, the bottom to turn around.

On "press enter" pages, tap anywhere (or the CONTINUE button) to go on.

The strip at the bottom: ESC, YES, NO, ENTER, KEYS (keyboard), SWAP and BOOK (this manual). A key the game is not asking for is grey and does nothing; YES and NO are grey when the big buttons above already show them.

## Exploring
While you explore, the touch screen shows an automap of the area: squares you have visited, walls (white), doors (gold) and an arrow for where you face. The map is remembered for each area.

The menu words (Area, Cast, View, Encamp, Search, Look) are big buttons beside the map.

## Combat
When a fight starts the game moves to the touch screen and the top screen shows each character's HP, AC and condition; the character whose turn it is is marked with ">".

The combat menu words (Move, View, Aim, Use, Cast, Turn, Quick, Done) appear as big buttons along the bottom.

To attack or cast at something, tap its square once to move the aiming cursor there (the game shows the range and the target), then tap the same square again to Target it.

If you swap the fight to the top screen (ZL), the touch screen becomes a touchpad: slide a finger to move the white pointer on the top screen, and tap to aim at the square under it (tap again to Target). Without the stylus, use the Aim menu: L / R pick the previous / next target, Manual gives a cursor the D-Pad moves.

Hold a diagonal on the D-Pad or Circle Pad to move diagonally.

## Typing and amounts
When the game asks "How much...", a number pad opens: ALL takes the most you can, CLEAR starts over, OK confirms, CANCEL backs out.

When the game wants a name or an answer, the keyboard opens and closes by itself. Naming a character has a RANDOM button.

## Journal and book
The game sometimes tells you to read an entry in the Adventurer's Journal. When it does, the BOOK button shows the entry number (for example J.12); tap it to open that entry. In the journal's grid of numbers, a gold corner marks the entries the game has sent you to so far.

In this book: the Circle Pad or C-Stick scrolls the text (hold to keep scrolling), or drag the stylus up or down on the touch screen; the D-Pad moves between the section buttons, and a section opens as you pick it; L / R go to the previous / next section (past the last section, on to the next tab); tap a section or a tab to open it; B or START closes the book.

Without the stylus, ZR, the D-Pad to BOOK, then A opens the book.

## 3D
Raise the 3D slider for depth in the dungeon view: near walls just behind the frame, far walls and the horizon deeper. Slide it all the way down for a flat picture; the top screen then uses its sharper 800-pixel-wide mode.

## Starting the game
The title menu waits on Play; the demo only runs if you pick Demo, and any button ends it.

Create characters from the start menu, add them to the party, then choose Begin Adventuring.

When a new character's numbers are rolled the game asks "Reroll stats?". The two buttons say what they do: REROLL rolls again, KEEP THESE goes on to the name. The highlight starts on KEEP THESE (the game's No).

Questions that quit, drop, overwrite or throw something away start on No.

Exit Game on the start menu asks the same "Exit Gold Box?" as the START menu, with the ring on NO.

If some of the game's files are missing from the card, a GAME FILES MISSING page lists them before the game starts.

## Saving and leaving
SAVE GAME in the START menu takes you to the game's own save list: while you explore it makes camp first (Encamp, then Save); in camp it opens Save. Pick a slot, A to I. SAVE GAME is grey where the game cannot be saved (the start menu, shops, combat, in the middle of an event). You can also do it by hand: Encamp, then Save.

Slot J is kept for the exit save. Exit Game in the START menu asks "Exit Gold Box?" and, while you are camping, on the wilderness map or in the 3D view, saves to slot J first ("Saving to slot J..."). To carry on later, choose Load Saved Game, then J. Closing the game from the HOME menu (HOME, then Close) saves to slot J the same way. Pressing HOME alone also saves to slot J, and sleep mode (closing the lid) does not.

If the game cannot save (for example in the middle of an event, or when the SD card is full or locked) it says NOT SAVED or SAVE FAILED and asks "EXIT ANYWAY" or "NO". It never quits after a failed save without asking. NO takes you back to the game: finish the event, then exit again.

A save is written to a temporary file first and only replaces the old save when it is complete, so a failed save leaves your last save as it was. The automap is saved the same way.

If the game stops on an error, a GAME STOPPED screen shows the error and says your last save is unchanged. Press A to close it. The details are in user/Crash Log.txt.

## Files and logs
Program: sdmc:/3ds/goldbox.3dsx (directly in /3ds).
Game files (your own .DAX files): sdmc:/3ds/goldbox/cotab/.
Saves, automaps and logs: sdmc:/3ds/goldbox/user/.
Optional sound samples: sdmc:/3ds/goldbox/sounds/.

The log user/Logs/Debugging.txt gets only the start, exit-save and error lines. To record everything the game does, create an empty file called debug.txt in sdmc:/3ds/goldbox/. It slows the game a little and rolls over at 1 MB; delete the file to switch it off.
